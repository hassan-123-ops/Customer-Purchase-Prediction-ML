# Customer Purchase Prediction Using Machine Learning

## Project Overview

Customer Purchase Prediction is a Machine Learning classification project that predicts whether a customer will purchase a product or not based on customer demographic information and purchasing behaviour.

The project compares four Machine Learning algorithms to identify the best-performing model for predicting customer purchase decisions.

## Objectives

The main objectives of this project are:

- Analyze customer demographic and purchasing data.
- Perform data exploration and preprocessing.
- Identify and remove duplicate records.
- Check missing values and outliers.
- Train multiple Machine Learning classification algorithms.
- Compare model performance using evaluation metrics.
- Identify the best-performing model.
- Understand the importance of customer features in purchase prediction.
